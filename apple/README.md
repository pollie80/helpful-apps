# Apple

One folder per app, each with its own README covering what it does, how to install it, and
anything it needs configured. Same idea as [`windows/`](../windows).

| App | What it is for |
| --- | --- |
| [claude-usage-bar](claude-usage-bar) | Your Claude subscription usage in the menu bar as a live percentage, read from the same endpoint the `/usage` panel uses rather than estimated from local logs. Pick which limit window the number tracks. |
